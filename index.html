Selected work

Work from my role at Apple, described in general terms.

Non-blocking CI test stage for a pull-request pipeline

Jenkins · Shell · C++ · Xcode

Problem
The pipeline proved the code compiled, but never ran the built tool. Runtime regressions only showed up after merge.
What I did
Added a stage that downloads a sample recording, runs the freshly built binary against it, and archives the output on the build page. A failure marks the stage red without failing the PR.
Result
Every PR now exercises the real binary, and reviewers can inspect the artifacts directly from the build.

Automated pass/fail classification from diagnostic logs

Python · log analysis · test automation

Problem
Deciding whether an authentication attempt passed, and how, meant reading logs by hand, which does not scale.
What I did
Wrote Python that parses the logs and classifies each outcome, then extended it to expand test coverage against captured device data.
Result
Wider automated coverage and consistent, repeatable verdicts instead of one-off manual reads.

Test-data capture and ingestion workflow

Shell · Python · data management

Problem
Test captures were being lost after recording, and weeks of work had to be redone.
What I did
Moved to upload-at-capture, backed up each set, and wrote a manifest so every capture is named, findable, and traceable.
Result
A reproducible capture set instead of a one-off folder, and a converter bug I surfaced along the way became mine to own and fix.

Playwright + pytest test framework

Athletic equipment inventory optimization

Python · pandas · Plotly · forecasting · Rutgers Track & Field

Problem
Rutgers Track & Field bought apparel in small, reactive batches and leaned on costly emergency orders.
What I did
Modeled size mix, replacement cycles and seasonal demand for an 84-athlete roster in Python, built an interactive dashboard, and presented the plan to Athletics leadership.
Result
A projected saving of about $8K a year (19%) and 40% fewer emergency orders. These are projections from the team's baseline budget plus an assumed bulk discount, and the athlete-level data is simulated; the dashboard says so.
